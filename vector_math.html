📝 1. قوانين الجمع والضرب

  • جمع المتجهات (المحصلة R): يمكن إيجادها بالرسم (طريقة المضلع/الذيل للرأس) أو بالتحليل للمركبات.
  • الضرب القياسي (النقطي): ناتجه كمية قياسية (رقم). قانونه: A · B = A B cos(θ)
  • الضرب المتجهي (التقاطعي): ناتجه كمية متجهة. قانونه: |A × B| = A B sin(θ)، واتجاهه يحدد بقاعدة اليد اليمنى.

🎮 2. مختبر جمع وضرب متجهين

🟢 مقدار المحصلة (R) = 0.0 🟣 الضرب القياسي (A·B) = 0.0 🟠 الضرب المتجهي |A×B| = 0.0
